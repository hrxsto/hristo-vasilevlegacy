# hristo.vasilevlegacy.net

Landing page pública de Hristo Vasilev, Consultor Independiente de Immunotec
(España). Publicada en <https://hristo.vasilevlegacy.net> vía GitHub Pages.

## Estructura

- `index.html` — la página completa: trilingüe (ES/EN/BG), sin JavaScript, sin trackers.
- `perfil-hristo.jpg`, `immunocal-sheet.jpg`, `favicon.png`, `apple-touch-icon.png` — recursos.
- `CNAME` — subdominio conectado a este repo.

## Cómo actualizar

1. Edita `index.html`. Cada texto existe en tres idiomas (clases `l-es`, `l-en`, `l-bg`);
   cualquier edición de contenido se hace en los tres idiomas a la vez.
2. Commit y push a `main` → GitHub Pages publica automáticamente (1-2 minutos).

## Reglas de contenido

- Sin promesas de ingresos ni de salud. Los avisos legales del pie son obligatorios.
- og:url, og:image y canonical apuntan a `https://hristo.vasilevlegacy.net/`.
- Este repo es público a propósito: contiene la foto y el WhatsApp de contacto de Hristo.
- Pendiente: enlazar el ID de consultor oficial en los enlaces de compra/inscripción
  cuando se confirme.
